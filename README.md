# polyu-agent — 香港理工大学校园信息问答助手（非官方）

基于 [nageoffer/ragent](https://github.com/nageoffer/ragent)（Apache-2.0，基线钉 tag **1.1.0**，commit `f64de341`）二次开发的垂直领域 RAG 问答项目。交付场景：**香港理工大学校园信息问答**——面向 PolyU 学生与教职工的教务注册、图书馆、校园设施预订、学生服务、奖助学金、重要日程与截止时间等信息咨询助手，带引用溯源与定时资讯更新。

项目优先级为 **B > A > C**：以可验证的企业级工程、规划和开发能力为首要目标，以真实学生需求作为产品验证输入，以真实运行和未来合作展示作为后续目标。

## 重要声明

- **本项目为个人独立项目，与香港理工大学无官方关联。** 回答内容来自公开官网信息，仅供参考，一切以学校官方发布为准。
- **官方答案数据来源限于符合准入规则的公开网页**（polyu.edu.hk 及各部门站点，按 host 检查 robots.txt、访问属性和条款）。需要 NetID/SSO、认证会话、个性化信息或标记为 internal/confidential/staff only 的内容不进入知识库；门户域名下公开正文按页面级规则判断。
- 小红书、贴吧等社交媒体只用于脱敏后的真实需求和评测集；社区回答不是标准答案。后续可提供相关社区问题链接，但与官方答案分离，不复制帖子回答。
- 本项目为开源底座二次开发，非从零自研。底座能力（混合检索引擎、摄取管线、模型路由与容错、管理端等）来自 nageoffer/ragent；二开工作集中在**业务域内容工程、检索链路落地与多语言化**。
- 保留底座 Apache-2.0 许可证（[LICENSE](./LICENSE)）与上游 README（[README.upstream.md](./README.upstream.md)）；上游 main 分支正向 2.0 演进，本项目不跟随，固定以 1.1.0 为基线。

## 解决什么问题

PolyU 信息分散在数十个部门站点（教务处 AR、学生事务处 SAO、包玉刚图书馆、ITS……），学生想弄清"怎么订游泳池""图书馆打印机怎么用""Add/Drop 怎么操作"这类问题，往往要翻多个文档，或去小红书求助有经验的人。本项目用**带引用溯源的 RAG 问答**聚合这些公开信息：

| 能力 | 说明 |
| --- | --- |
| 分域问答 | 按部门/场景划分知识库 + 意图树路由（教务注册 / 图书馆 / 校园设施 / 学生服务 / 奖助 / 国际交流…） |
| 引用溯源 | 回答内联引用标注 + 来源面板 + 官网原文预览 |
| 定时更新 | URL 来源文档按 cron 增量刷新（底座原生）；资讯流（定时发现 → 自动分类 → 信息流展示）为上线后机动项 |
| 多语言 | 首发正式支持简体中文与英文；底层保留三语文档身份和跨语检索能力，繁体中文先做兼容性冒烟，后续再正式开放 |
| 真实需求闭环 | 社交媒体问题作为 Golden Set 与口语化问法来源；线上失败问题只保留脱敏场景和诊断信息，异步生成知识缺口报告 |

## 场景规模（数字靶）

| 指标 | 目标 | 口径 |
| --- | --- | --- |
| 知识库语料 | 首发覆盖 100–300 个高价值官方来源（教务注册 / 图书馆 / 学生服务等高频问题域优先）；全站扩充为上线后机制 | 公开网页为主，按部门分库 |
| 意图树 | v0：3 域 10–15 个意图（随评测基线建立）；语料扩充后 v1：15–25 个意图 | 教务注册 / 图书馆 / 设施预订 / 学生服务 / 奖助 / 日程节点 / 无关拒答等 |
| 评测集 | 首发 30–60 道人工审核核心题 + 约 20 道词法检索挑战题；扩充至 80–100 条为后续迭代 | 分层：精确条文 / 语义泛化 / 时效敏感（过期通知=禁止引用集）/ 无答案拒答 |

## 快速开始

环境与启动以底座文档为准（[README.upstream.md](./README.upstream.md)、`bootstrap/src/main/resources/application.yaml`）。运行时文件存储复用同机私有 S3 兼容存储（MinIO），不使用托管对象存储服务。检索采用 pgvector 向量 + Elasticsearch 关键词双通道融合（ES 9.4.2 + IK，经词法检索实测达标后开启，保留整体回退开关）；Milvus / LightRAG 默认关闭。生产部署（容器镜像、单机编排、部署流水线）见 [deploy/README.md](./deploy/README.md)。

## 路线图

- **公共 V1（进行中）**：100–300 个高价值官方来源语料管线、pgvector + Elasticsearch 混合检索、意图树与双语提示词场景化、匿名试用 + 注册登录、公开答案分享（不可变快照）、单机 Docker Compose 部署与压测——先以有限覆盖提供可信服务，再按真实需求扩充
- **上线后迭代**：全站语料扩充、完整移动端适配、资讯流模块（定时发现 → 自动分类 → 信息流展示）、繁中正式支持
- **机动扩展**：校历/截止日期 MCP 工具、LightRAG 图通道、视合规与反馈评估与校方接触可能
