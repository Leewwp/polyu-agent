# polyu-agent — 香港理工大学校园信息问答助手（非官方）

基于 [nageoffer/ragent](https://github.com/nageoffer/ragent)（Apache-2.0，基线钉 tag **1.1.0**，commit `f64de341`）二次开发的垂直领域 RAG 问答项目。交付场景：**香港理工大学校园信息问答**——面向 PolyU 学生与教职工的教务注册、图书馆、校园设施预订、学生服务、奖助学金、重要日程与截止时间等信息咨询助手，带引用溯源与定时资讯更新。

## 重要声明

- **本项目为个人独立项目，与香港理工大学无官方关联。** 回答内容来自公开官网信息，仅供参考，一切以学校官方发布为准。
- **数据来源限于公开网页**（polyu.edu.hk 及各部门站点，遵守 robots.txt）。不抓取、不存储任何需 NetID 登录的门户内容（eStudent / POSS / myPolyU 等）。
- 本项目为开源底座二次开发，非从零自研。底座能力（混合检索引擎、摄取管线、模型路由与容错、管理端等）来自 nageoffer/ragent；二开工作集中在**业务域内容工程、资讯流模块与双语化**，全部改动逐条记录于 [CHANGES.md](./CHANGES.md)。
- 保留底座 Apache-2.0 许可证（[LICENSE](./LICENSE)）与上游 README（[README.upstream.md](./README.upstream.md)）；上游 main 分支正向 2.0 演进，本项目不跟随，固定以 1.1.0 为基线。

## 解决什么问题

PolyU 信息分散在数十个部门站点（教务处 AR、学生事务处 SAO、包玉刚图书馆、ITS……），学生想弄清"怎么订游泳池""图书馆打印机怎么用""Add/Drop 怎么操作"这类问题，往往要翻多个文档，或去小红书求助有经验的人。本项目用**带引用溯源的 RAG 问答**聚合这些公开信息：

| 能力 | 说明 |
| --- | --- |
| 分域问答 | 按部门/场景划分知识库 + 意图树路由（教务注册 / 图书馆 / 校园设施 / 学生服务 / 奖助 / 国际交流…） |
| 引用溯源 | 回答内联引用标注 + 来源面板 + 官网原文预览 |
| 定时更新 | URL 来源文档按 cron 增量刷新（底座原生）+ 资讯流模块：定时发现 → 自动分类 → 信息流展示（新增开发） |
| 双语 | 英/中双语文档与问答（官网本身三语并行，繁简经 OpenCC 归一） |

## 场景规模（数字靶）

| 指标 | 目标 | 口径 |
| --- | --- | --- |
| 知识库语料 | Phase 0：3 个部门子站 500–1500 页；Phase 1 全站 | 公开网页为主，按部门分库 |
| 意图树 | 15–25 个意图 | 教务注册 / 图书馆 / 设施预订 / 学生服务 / 奖助 / 日程节点 / 无关拒答等 |
| 评测集 | 80–100 条 | 分层：精确条文 / 语义泛化 / 时效敏感（过期通知=禁止引用集）/ 无答案拒答 |

完整规划见 [project-docs/01-项目规划与路线图.md](./project-docs/01-项目规划与路线图.md)。

## 快速开始

环境与启动以底座文档为准（[README.upstream.md](./README.upstream.md)、`bootstrap/src/main/resources/application.yaml`）。最小中间件栈：PostgreSQL + Redis + RocketMQ + MinIO（默认向量库为 pg；Milvus / ES / LightRAG 默认关闭，作为后续旋钮）。

## 路线图

- **Phase 0（POC）**：AR + 图书馆 + SAO 三个公开子站语料管线，意图树 v1，双语提示词，评测集 v1——验证"公开官网语料能否答好小红书式问题"
- **Phase 1（交付核心）**：资讯流模块（定时发现 → 自动分类 → 信息流展示，参考 aihot.virxact.com 的聚合设计）、前端双语化（EN/繁中）、全站语料扩充（A-Z 索引）
- **Phase 2（扩展，机动）**：校历/截止日期 MCP 工具、LightRAG 图通道、视合规与反馈评估官方合作可能
