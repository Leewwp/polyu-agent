# PostgreSQL 数据库脚本

## 全量初始化

- `schema_pg.sql`：最新版本的完整表结构
- `init_data_pg.sql`：最新版本的初始化数据

新环境直接按顺序执行这两个文件，不需要再执行历史升级脚本

## 增量升级

`upgrades/` 按开发周期划分目录：v1.0 发布后先后产生 `v1.1.0/` 与 `v2.0.0/` 两个目录，**`v2.0.0/` 为现行追加目录（2026-08 起的新脚本一律进 v2.0.0，如 `260919_agent_conversation_share.sql`）**

目录内的脚本使用首次提交日期和变更含义命名：

- 默认格式：`yyMMdd_变更含义.sql`
- 同一天有多个脚本时：`yyMMdd_两位顺序号_变更含义.sql`

已有环境从「未执行过的最旧脚本」起按文件名顺序逐个执行，不合并过程脚本。后续正式版本在 `upgrades/` 下新建对应目录并继续使用相同的命名规则

已经对外提供或被其他开发者执行过的升级脚本保持原目录原名不变，新的数据库变更继续在现行目录追加独立脚本
