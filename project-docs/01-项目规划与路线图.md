# 01 · 项目规划与路线图（PolyU 校园信息问答）

> 基线：nageoffer/ragent 1.1.0（commit `f64de341`）。本文档为交付线 A（PolyU 场景）的总体规划，改动落点逐条记录于 [`../CHANGES.md`](../CHANGES.md)。
> 调研日期：2026-09-03。

## 一、项目定位

- **用户**：香港理工大学学生（主）/ 教职工（次）
- **场景**：校园信息问答——教务注册、图书馆服务、设施预订、学生服务、奖助学金、国际交流、重要日程与截止时间等
- **形态**：带引用溯源的 RAG 问答 + 定时更新的资讯流（信息聚合设计参考 [aihot.virxact.com](https://aihot.virxact.com)：日期 + 分类 + 热度 + 来源）
- **身份**：非官方个人项目，与 PolyU 无关联；回答仅供参考，以官方发布为准
- **赛道结论**：校方已有通用 AI 布局（PolyU GenAI 平台、AITU 导师系统、TIMS VAT 聊天机器人），但均非"跨部门、带引用溯源的校园信息问答"形态，该生态位当前空缺；风险在于校方可能自建，以及非官方项目的合规边界

## 二、信息源盘点

### 公开层（v1 数据来源）

| 来源 | 覆盖内容 | 采集方式 |
| --- | --- | --- |
| polyu.edu.hk 主站 + [A-Z 索引](https://www.polyu.edu.hk/atoz/) | 全部门入口、新闻、通知 | sitemap（`home.xml` / `news-sitemap.xml`）做种子 |
| [教务处 AR](https://www.polyu.edu.hk/ar/) | 注册、选课 Add/Drop、考试、毕业、表格 | HttpUrlFetcher + 按文档 cron 刷新 |
| [包玉刚图书馆](https://www.lib.polyu.edu.hk/) | 开放时间、设施、借阅、电子资源 | 同上 |
| [学生事务处 SAO](https://www.polyu.edu.hk/sao/) | 奖助、非本地生、就业、公开服务说明 | 同上 |
| 微信公众号（机动） | 中文通知 | 无公开 API，导出/桥接成本高，Phase 1 视需要 |

- **robots.txt 结论**（2026-09-03 核实）：全站对通用爬虫开放，仅禁约 90 个部门站内搜索结果页（`/[dept]/search-result` 模式）；主动提供两个 sitemap。采集器必须将禁抓路径写入过滤规则。
- **三语处理**：同一页面英/繁/简三版本。入库策略：繁体经 OpenCC 归一为简体（或反之，开发时定）+ 英文版，两版本以同一 doc ID 关联，避免三倍冗余污染检索。

### 登录层（红线，不进语料库）

eStudent、POSS、myPolyU、Student Account Portal 等需 NetID 的系统内容**不做集中采集**。理由：账号使用条款约束 + "自己能登录 ≠ 可替所有人抓取分发"的合规风险。若未来做，只能是"用户自带会话、数据不落库"的形态，且需重新评估。

## 三、领域划分与意图树草案

对应底座意图树三级结构（DOMAIN / CATEGORY / TOPIC），每意图节点绑定知识库集合与 topK：

| DOMAIN | CATEGORY（示例） | 知识库集合 |
| --- | --- | --- |
| 教务注册 | 选课 Add/Drop、学期日历、考试、毕业 | ar |
| 图书馆 | 开放时间、设施使用、借阅、电子资源 | lib |
| 校园设施与生活 | 体育设施预订、打印、餐饮、宿舍 | campus |
| 学生服务与奖助 | 奖学金、经济援助、就业、非本地生 | sao |
| 国际交流 | 交换、暑期项目 | international |
| 科研发展 | 研究生科研支持 | research |
| 资讯与日程 | 荣誉、重要通知、截止时间 | news |
| 无关拒答 | 与 PolyU 无关的问题低置信度澄清/拒答 | — |

**Phase 0 只建前 3 个域**（ar / lib / campus），验证检索质量后再扩。

## 四、功能规划

1. **问答核心（底座原生）**：多通道检索（v1 纯向量）+ RRF + 重排 + 引用溯源，SSE 流式
2. **定时更新（部分原生）**：
   - 原生：URL 来源文档按文档粒度 cron 增量刷新（`KnowledgeDocumentScheduleJob`），不重建索引
   - 新增：**资讯流模块**——发现型爬虫（news-sitemap + 部门新闻页）→ 自动分类（荣誉 / 重要事项 / 截止时间，LLM 分类或复用意图树）→ 入库打标 → 前端信息流页面
3. **双语化**：前端 i18n（EN / 繁中优先）；提示词槽双语改写；检索 Embedding 当前基线为 Qwen3-Embedding-8B（原生多语），中文提问检索英文文档的实际效果以 Phase 0M 跨语评测为准（见 [`03-Phase0M-模型选型与评测计划.md`](./03-Phase0M-模型选型与评测计划.md)）
4. **元数据**：chunk `extras` 写 department / audience / effective_date / language，支撑过滤与"过期通知禁止引用"评测

| 需求 | 底座落点 | 状态 |

## 六、评测体系

- **对照组 B**：底座官方"企业知识助手"示例（原样语料 / 意图树 / 提示词）本地跑通，同一评测口径出基线数字
- **交付线 A**：PolyU 场景，golden set 80–100 条，分层：
  - 精确条文：具体数字 / 时间 / 地点（图书馆开放时间、某表格下载入口）
  - 语义泛化：口语化问法（小红书式："怎么抢课""打印机怎么用"）
  - 时效敏感：过期通知 = 禁止引用集，引用旧版即扣分
  - 无答案拒答：语料外问题不得编造
- **达标线**：A 的 HitRate@10 / MRR ≥ B 基线的 85–90%，意图 Top-1 ≥ 80%，拒答无误触
- **D11 检查点不达标降级链**：域收窄（三域减一）→ 开 ES 混合检索 → 提示词调优
- **模型层横评独立进行**：Embedding / Reranker / Chat 的候选对比与锁定按 [`03-Phase0M-模型选型与评测计划.md`](./03-Phase0M-模型选型与评测计划.md) 分层执行——本节消融是"固定模型、比检索管线配置"，03 是"固定管线、比模型"，两者共用评测标注规范

## 七、路线图

### Phase 0 · POC —— 验证"公开官网语料能否答好小红书式问题"

Phase 0 内部按子阶段顺序推进：

- **0A · 底座适配性审计（已完成）**：ragent 1.1.0 逐项代码审计，结论 Go，见 [`02-Phase0-ragent底座适配性审计.md`](./02-Phase0-ragent底座适配性审计.md)
- **0B · 最小运行环境与垂直切片**：本地环境搭建 + Library 20–50 条种子页入库 + 三语问法验证（设计见 02 §7；实施记录顺延编号 04）
- **0M · 模型选型决策门**：在最小运行环境和测试语料准备完成之后、**大规模语料入库之前**执行——Embedding 分层评测并优先锁定（锁定后全量入库即绑定该向量空间，换型需全量重建），Reranker 与 Chat 候选随后分层评测。**未过此门不启动全量采集入库**。见 [`03-Phase0M-模型选型与评测计划.md`](./03-Phase0M-模型选型与评测计划.md)
- **0C · 大规模语料与 POC 收口**：采集 AR / Library / SAO 三子站，目标 500–1500 页；繁简归一 + 标题链 + extras 元数据（extras 落点按 02 §4.4 修正）；意图树 v1（3 域 10–15 意图）、术语映射 v1（50–100 条）；提示词槽双语改写（6 槽）；评测集 v1（60–80 条）+ B 基线 + A 数字；**产出：可演示问答 + 评测报告，据数字决定是否进 Phase 1**

### Phase 1 · 交付核心

- 资讯流模块（发现型爬虫 + 自动分类 + 信息流页面）
- 前端 i18n（EN / 繁中）+ 主题调整（CSS 变量，弱化商标元素，非官方声明常驻）
- 全站语料扩充（A-Z 索引全量部门）、意图树扩至 15–25 意图、评测集扩至 80–100 条

### Phase 2 · 扩展（机动）

- MCP 工具：校历查询、截止日期提醒（公开数据）
- LightRAG 图通道（政策 ↔ 流程 ↔ 表格 跨文档关联）
- 视合规与反馈：登录态形态重评估 / 与校方接触（带评测数字的原型是最好的提案）

## 八、合规红线（长期有效）

1. 界面与 README 常驻**非官方声明**；避免校名校徽做主标识
2. 只采公开网页；robots.txt 禁抓路径写入采集器过滤规则
3. 登录后内容不进语料库；个人账号抓取 ≠ 可集中分发
4. 答案级引用 + 回链官网，不做整站镜像
5. 内容时效标注（effective_date），过期信息进禁止引用集
